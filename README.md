## Indicadores que serão desenvolvidos

Os indicadores previstos para desenvolvimento a partir dos dados do sistema de chamados são:

- Total de chamados
- Chamados por mês
- Chamados por status
- Chamados por prioridade
- Chamados por analista
- Chamados por categoria
- Chamados por fila
- Chamados por cliente/organização
- Percentual de cumprimento de SLA
- Tempo médio de resolução
- Tempo médio por status
- Satisfação média dos usuários (CSAT)
- CSAT por analista
